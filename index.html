Local AI agents, visible in your terminal.

KLAW is an early local-first AI runtime for developers who want the plan, file writes, shell commands, output, and failures to stay visible. No SaaS dashboard. No fake success. Just a small CLI you can inspect, fork, and run locally.

Install on your machine.

KLAW runs through Node and npm. Configure your own provider key, then keep generated work inside a local workspace. The npm package still serves 0.1.4 until v0.2 publish access is restored, so use the GitHub install for now.

Windows PowerShell

node --version
npm --version
npm install -g github:janpaul80/klaw#main
$env:OPENAI_API_KEY="your_openai_api_key"
klaw doctor
klaw init

WSL / Linux

node --version
npm --version
npm install -g github:janpaul80/klaw#main
export OPENAI_API_KEY="your_openai_api_key"
klaw doctor
klaw init

macOS

node --version
npm --version
npm install -g github:janpaul80/klaw#main
export OPENAI_API_KEY="your_openai_api_key"
klaw doctor
klaw init

A small runtime, not a platform.

KLAW v0.2.0 is about making the first loop real: provider-backed planning, generated file contents, real shell commands, honest error capture, and one basic repair attempt.

Architect

Asks the configured provider for a structured JSON plan before work begins.

Writer

Generates complete file contents and blocks writes outside the selected workspace.

Shell

Requests permission, streams stdout/stderr, captures exit codes, and reports failures.

Fixer

For `npm install` or `npm run dev` failures, applies one provider-suggested repair and retries once.

Memory

Keeps short execution history under `~/.klaw` so runs can be inspected later.

Provider

Starts with OpenAI via `OPENAI_API_KEY`; Ollama and other providers can follow later.

Honest by design.

KLAW should not fake success, skip installs, pretend a server is running, or hide stderr. If something fails, the terminal should say so.

Known limitations.

This is an early runtime, not production-ready autonomous engineering software.

OpenAI is the first real provider. More providers come later.

The repair loop is simple and intentionally retries once.

KLAW is not a secure sandbox for untrusted code.
