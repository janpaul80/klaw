What is KLAW?

KLAW is a local-first AI runtime that helps developers execute tasks through transparent terminal-based agents. Instead of hiding decisions behind a cloud service, KLAW keeps planning, file creation, shell execution, and repair attempts visible and understandable.

Agent Workflow

User Prompt ↓ Architect ↓ Writer ↓ Shell ↓ Fixer ↓ Workspace

Features

Local-first execution

Run AI agents entirely on your machine. No cloud dependency.

Transparent terminal logs

Every step is visible in your terminal. No hidden state.

Real shell command execution

Commands run for real. Exit codes are honest. Failures are reported.

Workspace isolation

Projects stay in ~/.klaw/workspaces. File writes are sandboxed.

Memory logging

Execution history is saved for later inspection.

Provider support

Connect to OpenAI, OpenRouter, Ollama, Anthropic, Gemini, or Langdock.

Open-source

Installation

Install KLAW via npm and configure your preferred provider.

Windows PowerShell

node --version
npm --version
npm install -g @phartmann80/klaw
$env:OPENAI_API_KEY="your_key"
klaw doctor
klaw init

WSL / Linux

node --version
npm --version
npm install -g @phartmann80/klaw
export OPENAI_API_KEY="your_key"
klaw doctor
klaw init

macOS

node --version
npm --version
npm install -g @phartmann80/klaw
export OPENAI_API_KEY="your_key"
klaw doctor
klaw init

Run a task

klaw run "create a hello script"
klaw run "build a landing page" --workspace ./my-app
klaw logs
klaw doctor
